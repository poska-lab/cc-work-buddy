# work-buddy

Claude Code の入力欄の上に、Claude くん（Claude Code の起動画面のキャラ）と「今何をしているか」を表示する mod（function hooks plugin）です。絵と文字を同じ 3 行に収め、上に 1 行あけます。

> **非公式の mod です。** Anthropic とは関係がなく、Anthropic が作ったり認めたりしたものではありません。Claude、Claude Code、起動画面のキャラクターは Anthropic のものです。
>
> An unofficial, fan-made mod for Claude Code: a little Claude above your prompt that shows what it is doing right now. Not affiliated with or endorsed by Anthropic.

```
  ▄▄▄▄▄▄   !!!  「?」「!」の動きを確認している
 ▄█▘██▝█▄       「?」は増えるが「!」は全フレーム同じで動いていない
  ▜▜▀▀▛▛        実行中: Print each mark  ツール 3 回（Bash 2 · Read 1）
```

| 行 | 中身 | 更新 |
|---|---|---|
| 1 行目 | 全体として何をしているか（Haiku。ターンの始めは依頼の頭） | 目的が変わったときだけ言い換える |
| 2 行目 | 直近で何をして、何がわかったか（Haiku） | ツールが終わるたび（4 秒に 1 回まで） |
| 3 行目 | 今の具体的な作業（下のルールの一言）と、ツールの回数 | すぐ |

- 1・2 行目は、ツールが終わったときに Haiku 5.5（`claude-haiku-5-5`、effort `low`）が 1 回の呼び出しでまとめます。前に呼んでから 4 秒たっていなければ呼ばず、失敗したときは前の行のままです。ターンが終わると 1 行目は状態の一言（できた！など）に戻り、2 行目は最後にわかったことを次のターンまで残します。終わったあとに届いた答えは捨てます。
- 3 行目は、ツールを使わずに考えている間は「考え中 12秒」、返事を書き始めたら「書いてる: …」に変わります。末尾に、そのターンのツールの回数をツールの名前ごとに薄く添えます（MCP のツールはまとめて MCP）。
- 見た目で区別できるよう、1 行目は太字、2 行目は Claude の色（変わった直後の 2 秒は太字）、3 行目は薄く、集計はさらに薄いグレーで描きます。色はテーマの色名で指定するので、ライトとダークのどちらでも読めます。
- 長い文は帯の幅に合わせて切ります。

## 表示の規則

| 出来事 | 状態 | 一言の例 |
|---|---|---|
| ターン開始 | thinking | 「<依頼の頭>」に取りかかってる |
| Read | reading | `<file>` を読んでる / `<file>` の 120 行目あたりを読んでる |
| Edit / Write / NotebookEdit | writing | `<file>` を書き換え中 / `<file>` を書き出し中 / `<file>` のセルを編集中 |
| Grep / Glob / ToolSearch | searching | 「`<pattern>`」を `<path>` から探してる / `<pattern>` に合うファイルを探してる |
| Bash | running | 実行中: `<description または command>` / 裏で実行中: … |
| WebSearch / WebFetch / MCP | browsing | 「`<query>`」をウェブ検索中 / `<host>` を読みに行ってる / Notion で notion-search を実行中 |
| Agent | delegating | `<subagent_type>` に頼んでる: `<description>` |
| Skill / TodoWrite / AskUserQuestion | thinking | スキル `<name>` を使ってる / 段取りを整理中（3 件） / あなたの答えを待ってる |
| ツールが失敗 / 拒否 | oops / denied | `<tool>` がうまくいかなかった… / `<tool>` は止められた |
| ターン終了 | done / stopped / crashed | できた！ / 中断しました・それは引き受けられなかった / エラーで止まっちゃった… |
| 起動直後 | idle | 待機中。なにかあれば呼んでね |

- 集計は、そのターンのツールの回数とツールごとの内訳です。ターンが終わると、かかった時間も添えます。
- 同じ作業が続いても単調にならないよう、いくつかの言い回しを順に使います。
- メインの loop だけを対象にし、サブエージェント内のイベントは表示しません。
- 3 行目は作業状態から作った定型文です。1・2 行目は Haiku が、依頼・Claude の書いた文・作業と結果からまとめたもので、モデルの内部推論ではありません。

## Claude くんの動き

- Claude くんは、起動画面のブロック文字（` ▐▛███▜▌` / `▝▜█████▛▘` / `  ▘▘ ▝▝`）を1文字2×2画素として読み直した 18×5 画素の絵です。もとと同じく2×2画素を四分割ブロック文字1文字で描くので、大きさはもとと同じ横 9 文字・3 行です。1文字に塗れるのは2色までなので、虹色は文字ごとに1色にし、涙は目と別の文字に置きます。体はテーマの claude 色 `#D77757`、目は `#1F1F1F` です。
- 作業中の状態（thinking から delegating まで）は、状態ごとのテンポで 4 コマをくり返します。実行中や書き換え中は 0.2 秒ごとに速く、考え中や読んでいるときは 0.5〜0.6 秒ごとにゆっくり動きます（目線・腕・跳ねる・左右の揺れ）。
- 頭の横の記号も動きます（考え中は `?` → `??` → `???`、実行中は `!` → `!!` → `!!!`、ウェブは `~` → `~~~`）。同じ作業が続くとき（Read が続くなど）は、動きを頭に戻さずそのまま続けます。
- 作業中は体が虹色に光り、色が流れます。流れ方（横・縦・全体いっせい・斜め）、始まりの色、回る向きは、状態が切り替わるたびに変わります。
- 表情は状況に合わせて使い分けます。目（点・細めた線）、口、涙で描き分け、腕・動き・頭の横の記号で補います。目と口は頭と胴の内側だけに置き、輪郭を切りません。

  | 状況 | 状態 | 表情とリアクション |
  |---|---|---|
  | 終わった | done | 喜び（目を細めて口を開ける、バンザイ）。虹色になって足踏みしながら 3 回跳ねる、`*` |
  | ツールが失敗した | oops | 驚き（目を開いて口を開ける）。`!?` と `?!` を入れ替えながら、びくっと震える |
  | ターンがエラーで止まった | crashed | 泣き（涙）。震える、`;` |
  | ツールを止められた | denied | むっ。左右をにらむ、`#` |
  | 中断・お断り | stopped | しょんぼり。左右を見てから目を伏せる、`...` |
  | 仲間に頼む | delegating | 左右の手を交互に振る、`>>>` |
  | 待機が 1 分続いた | idle ほか | 疲れ（目を細める）のあと、目を閉じて居眠り、`z` `zz` `zzz` |

- 落ち着いた状態（idle と、リアクションを終えた done / oops / crashed / denied / stopped）は、もとの claude 色で、ふわふわ浮きながらときどきまばたきして左右を見ます。1 分ほどたつと疲れた顔をしてから、目を閉じて `z` `zz` `zzz` と居眠りします。
- 絵は `Client`（描画側で動く要素）が自分の時計で動かします。コマが変わったとき（虹色の間は 0.1 秒ごと）だけ描き直し、コマごとにプラグインを呼び出しません。
- 表示を止めるときは、Plugins で `work-buddy` を無効にします。
- 帯（`AbovePrompt`）を描くのは terminal と desktop だけです。

一言のテンプレートと集計は [`hooks/mood.ts`](hooks/mood.ts)、Claude くんの絵・動き・色は [`hooks/clawd.ts`](hooks/clawd.ts)、絵を動かす `Client` は [`hooks/buddy.tsx`](hooks/buddy.tsx)、イベントの処理と帯の描画は [`hooks/register.tsx`](hooks/register.tsx) にあります。

## 設定とプライバシー

- 1・2 行目をまとめる Haiku 5.5 の呼び出しは、あなたのセッションの認証で行います（API キーは要りません。サブスクならその利用枠を使います）。この mod が自分でネットワークにつなぐことはなく、ファイルも読み書きしません。
- Haiku に送るのは、このターンの依頼（600 文字まで）、Claude が直近に書いた文（400 文字まで）、直近 6 件の作業の一言（ファイル名やコマンドの説明を含む）、いま終わった作業の結果の頭（600 文字まで）、いま出している 2 行です。ツールが終わったときに、4 秒に 1 回までしか呼びません。
- 送りたくないときは、設定の「Haiku で今の作業をまとめる」（`narrate`）をオフにします。インストールのときに出る設定画面か、`/config` で切り替えられます。オフのときは、3 行目のルールの一言と集計だけで動きます。

## 使い方

Claude Code の terminal で:

```
/plugin install work-buddy --marketplace poska-lab/cc-work-buddy
```

`Add marketplace?` に `y` で答え、範囲（user など）を選ぶと、その場で動き始めます。shell からなら:

```sh
claude plugin install work-buddy --marketplace poska-lab/cc-work-buddy
```

desktop アプリでは `/plugin` が使えないため、入力欄の「＋」→ Plugins → Add marketplace に `poska-lab/cc-work-buddy` を入れ、Add plugin で `work-buddy` を選びます。

クラウドのセッションでは plugin の画面表示が使えません。帯は、手元の terminal または desktop の Code タブのローカルセッションで表示されます。止めるときは Plugins で `work-buddy` を無効にします。

## 開発

checkout からそのセッションだけ読み込めます。

```sh
claude --plugin-dir .
claude plugin validate .
claude plugin test .
```
